# stage-d-ing-nieur
Amélioration du site web de la STIR Bizerte avec Spring Boot, React/Vite, MongoDB et un modèle IA en Python. Mise en place d’une architecture DevOps avec Docker et Azure for Students, création d’un cluster AKS et déploiement des services avec Kubernetes, afin d’assurer une solution moderne, scalable et automatisée.
